# 会計ルールの設定

`config/accounting-rules.example.json` は、立替経費とメール受領請求書を仕訳候補へ変換する決定表の例です。

- 売上はマネーフォワード クラウド請求書の標準連携を使い、この決定表では仕訳を作りません。
- サンプルルールは誤使用防止のため `enabled: false` です。
- 科目、部門、税区分は、MFクラウド会計に登録された名称と完全一致する値へ変更します。
- 一致するルールがない場合、同じ優先度で複数一致した場合、証憑がない場合は自動確定しません。
- 生成された仕訳候補は `needs_review` で始まります。これは仕訳出力制御用の状態です。
  立替経費には申請の承認工程を設けず、Drive格納を受付とします。
  現段階のCSV関数は `approved` の候補だけを受け付けますが、Drive取込CLIは
  CSV出力・自動確定をせず確認レポートまでで終了します。
- Drive取込では有効ルールの借方・貸方の税区分を必須にします。
  社員の精算先は店舗の取引先と区別し、貸方には社員のMF取引先名を使用します。

操作手順・データ形式・未実装範囲は [立替経費の取込手順](expense-intake.md) を参照してください。

## 優先順位

`priority` は数字が小さいほど優先されます。同じ優先度のルールが複数一致した場合は競合として人レビューへ送ります。

## 変更手順

1. MFクラウド会計から勘定科目、補助科目、部門、税区分の一覧を確認する。
2. 経理担当者または税理士が取引パターンごとの設定値を決める。
3. サンプルをコピーして正式な設定ファイルを作る。
4. 過去取引の正解データでテストする。
5. 承認されたルールだけ `enabled: true` にする。
